# ePortfolio Project

This ePortfolio project showcases my work, skills, and experiences. It is designed to provide a comprehensive overview of my professional journey.

## Project Structure

```
ePortfolio
├── assets
│   ├── css
│   │   └── reflection.css
│   ├── images
│   │   └── Headshot.JPG
│   └── js
│       └── scripts.js
├── index.html
├── about.html
├── capstone-project.html
├── project-work.html
├── reflection.html
└── README.md
```

## Files Description

- **index.html**: The main entry point for the website. It introduces the ePortfolio and provides navigation to other sections.
- **about.html**: Contains information about me, including a professional bio, personal interests, and contact details. It also includes a circular profile photo positioned in the top-right corner.

- **capstone-project.html**: Details the Capstone Project, including its objectives, outcomes, and my contributions.

- **project-work.html**: Highlights various school projects, including detailed descriptions of specific projects like the "Post Assembly Thermal Annealing of Microelectromechanical Devices."

- **reflection.html**: Contains reflections on my learning journey, including insights into the skills and attributes I developed during the Capstone course.

- **assets/css/reflection.css**: Defines the styles for the ePortfolio, including layout, typography, and visual elements like the circular profile photo.

- **assets/images/Headshot.JPG**: A profile photo used in the `about.html` and `index.html` pages.

- **assets/js/scripts.js**: Contains JavaScript functionality, such as toggling the navigation menu.

## Setup Instructions

1. Clone the repository to your local machine.
2. Open the project folder in your preferred code editor.
3. Open `index.html` in a web browser to view the ePortfolio.
4. Modify the HTML and CSS files as needed to customize your ePortfolio.

## Usage

Feel free to explore the different sections of the ePortfolio. You can add your own projects, skills, and contact information to make it uniquely yours.
